# ANHVN VPN

ANHVN VPN là ứng dụng proxy client thế hệ mới dành cho Android, kết hợp giữa sự ổn định của lõi proxy hàng đầu và giao diện hiện đại Material 3 (FlClash card-style dashboard).

[![Android API](https://img.shields.io/badge/Android-API%2024%2B-brightgreen.svg)](https://developer.android.com)
[![Architecture](https://img.shields.io/badge/Architecture-ARM64--v8a-blue.svg)](https://github.com/anhvn00/ANH-VPN)
[![License](https://img.shields.io/badge/License-GPLv3-orange.svg)](LICENSE)

---

## Tính Năng Nổi Bật (Features)

- **Đa nhân Core thông minh**: Hỗ trợ linh hoạt **Xray**, **V2Ray**, và **Mihomo (Clash.Meta)**.
- **Giao diện Kép (Dual UI Mode)**:
  - **Chế độ Hiện Đại (Modern Dashboard)**: Thiết kế Material 3 Card kiểu FlClash, hiển thị tốc độ mạng real-time, nút nguồn lớn, chuyển core nhanh.
  - **Chế độ Cổ Điển (Classic)**: Giao diện danh sách server truyền thống, nhẹ và ổn định.
- **Tối ưu hóa phần cứng**: Biên dịch tối ưu cho `arm64-v8a`, tiết kiệm pin và tải siêu mượt.
- **Bảo mật tối đa**: Hoàn toàn không ghi log, dữ liệu lưu trữ cục bộ bảo mật bằng MMKV.
